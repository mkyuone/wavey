# SectionFinder

Project repo for SectionFinder, a tiny static web app for opening an audio file locally, viewing an interactive waveform, and jumping through audible sections or silent gaps.

## Run

Open `index.html` in a browser, or serve the folder with any static file server.

## Chrome extension

Load the project folder in Chrome from `chrome://extensions` with Developer Mode enabled. The packaged source archive is available at `dist/sectionfinder-chrome-extension.zip`; unzip it before using Chrome's "Load unpacked" flow. Clicking the extension toolbar button opens SectionFinder in a full tab.
